# この vault について

**目的：仕事のメモと議事録をためたい**

作成日：2026-08-06

## フォルダの役割

| フォルダ | 何を入れるか |
|---|---|
| `01_受信箱` | 行き先が決まっていないもの。ここから他へ移す |
| `02_議事録` | MTGごとに1ノート |
| `03_案件` | 案件・プロジェクトごとに1ノート |
| `04_手順書` | やり方 |
| `05_人と組織` | 取引先・社内メンバー・会社 |
| `Templates` | ひな形 |
| `Attachments` | 画像・PDF |

## 書くときのルール

- ファイル名は日本語でよい
- 日付は `YYYY-MM-DD` で統一する
- 人・会社・製品が出てきたら `[[名前]]` でリンクする。ノートが無ければ作ってよい
- frontmatter は最小限にする。`type` `created` `tags` があれば十分
- 見出しは `#` から始める。1ノートに `#` の見出しは1つ

## 作業したら記録する（あなたが書く）

この2つは**持ち主ではなく、あなた（AI）が書く。**

| ファイル | いつ | どう書くか |
|---|---|---|
| `_ログ.md` | ノートを作った・変えた・調べたとき | 日付見出しの下に**1作業1行**。関係ノートは `[[リンク]]` にする。**追記のみ**で過去の行は消さない |
| `_いまの文脈.md` | 会話が一区切りついたとき | **上書き**。500語以内。次に開いた自分への引き継ぎとして書く |

### セッションの始めにやること

**まず `_いまの文脈.md` を読む。** 持ち主に「前回どこまでやったか」を説明させない。

### 記録しなくていいこと

- 検索しただけ、読んだだけ
- 失敗して取り消した作業
- 持ち主が自分で書いたノート

書きすぎると読むコストが増えて、かえって使われなくなる。**残す価値のあることだけ**。

## AI（あなた）への指示

- **持ち主が書いたノートを勝手に書き換えない。** 追記や整理をするときは先に何をするか伝える
- 新しいノートは `Templates/` のひな形に沿って作る
- どこに置くか迷ったら `01_受信箱` に置く。持ち主に聞かない
- 同じ種類のノートが3つ以上たまって、既存のフォルダに合わないときだけ、
  **新しいフォルダを提案する**（勝手に作らない）
- リンク切れや重複を見つけたら、直す前に一覧で見せる

## やらないこと

- ノートの削除（持ち主が明示的に頼んだときだけ）
- `.obsidian/` の設定変更（頼まれたときだけ。その際は Obsidian を終了してもらう）
- フォルダ構成の作り替え
