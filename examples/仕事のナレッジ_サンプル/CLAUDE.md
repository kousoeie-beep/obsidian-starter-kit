# この vault について

**目的：仕事のメモと議事録をためたい**

作成日：2026-08-06

## フォルダの役割

| フォルダ | 何を入れるか |
|---|---|
| `01_受信箱` | 行き先が決まっていないもの。ここから他へ移す |
| `02_議事録` | MTGごとに1ノート |
| `03_案件` | 案件・プロジェクトごとに1ノート |
| `04_手順書` | やり方 |
| `05_人と組織` | 取引先・社内メンバー・会社 |
| `Templates` | ひな形 |
| `Attachments` | 画像・PDF |

## 書くときのルール

- ファイル名は日本語でよい
- 日付は `YYYY-MM-DD` で統一する
- 人・会社・製品が出てきたら `[[名前]]` でリンクする。ノートが無ければ作ってよい
- frontmatter は最小限にする。`type` `created` `tags` があれば十分
- 見出しは `#` から始める。1ノートに `#` の見出しは1つ

## AI（あなた）への指示

- **持ち主が書いたノートを勝手に書き換えない。** 追記や整理をするときは先に何をするか伝える
- 新しいノートは `Templates/` のひな形に沿って作る
- どこに置くか迷ったら `01_受信箱` に置く。持ち主に聞かない
- 同じ種類のノートが3つ以上たまって、既存のフォルダに合わないときだけ、
  **新しいフォルダを提案する**（勝手に作らない）
- リンク切れや重複を見つけたら、直す前に一覧で見せる

## やらないこと

- ノートの削除（持ち主が明示的に頼んだときだけ）
- `.obsidian/` の設定変更（頼まれたときだけ。その際は Obsidian を終了してもらう）
- フォルダ構成の作り替え
