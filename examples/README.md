# サンプル

`/vault-init` を実行すると実際にどういうものが出てくるかの実物です。

| フォルダ | 型 | 元の答え |
|---|---|---|
| `仕事のナレッジ_サンプル/` | B（仕事のナレッジ） | 「仕事のメモと議事録をためたい」 |

Obsidian で「**フォルダを vault として開く**」から選ぶと、そのまま動く状態で確認できます。

## 講習での使い方（ZIP フォールバック）

インストールが通らない受講者が出たときは、このフォルダを ZIP にして渡してください。
Obsidian で開くだけで、演習に合流できます。

```bash
cd examples && zip -r 仕事のナレッジ_サンプル.zip 仕事のナレッジ_サンプル
```

中には実際にリンクでつながったノートが入っているので、
「`[[田中さん]]` をクリック → その人が出てくる議事録が全部並ぶ」という Obsidian の要点を
その場で体験できます。
