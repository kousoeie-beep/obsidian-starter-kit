description: 今の会話の中身を vault のノートとして残す。どこに置くか・何という名前にするかはこちらで決める。
---

`vault-operate` スキルの「保存」の節を読んでから実行してください。

## 手順

1. `CLAUDE.md` を読んで、この vault の構成とルールを把握する
2. 会話の中から**残す価値があるもの**を選ぶ（全部は残さない）
   - 決まったこと／分かったこと／手順／調べた結果
   - 雑談、試行錯誤の途中経過、失敗して捨てた案は残さない
3. 適切なテンプレートとフォルダを選ぶ。**ユーザーには聞かない**
4. 同じ名前のノートが既にあれば、**新規作成せず追記するか**を聞く
5. 作ったら、パスと中身の要約を見せる

## 引数

| 書き方 | 動き |
|---|---|
| `/vault-save` | 会話全体から自動で選んで保存 |
| `/vault-save <名前>` | その名前で保存（命名の質問を省く） |
| `/vault-save 議事録` | 議事録テンプレートで保存 |
| `/vault-save まとめ` | 調べた結果を1ページにまとめて保存 |

## 書き方のルール

- **元の会話をそのまま貼らない。** 読み返して意味が分かる形に書き直す
- 人名・会社名・製品名が出てきたら `[[名前]]` にする。リンク先が無くてもよい
- 出典（URL・ファイル名・会話の日付）を必ず書く
- frontmatter は `type` `created` `tags` の3つがあれば足りる

## vault が無いとき

`.obsidian/` が見つからない場合は「まだ vault がありません。`/vault-init` で作れます」とだけ言う。
勝手にフォルダを作らない。
