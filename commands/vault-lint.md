---
description: vault の散らかりを点検する。直す前に必ず一覧で見せて、承認されたものだけ直す。
---

`vault-operate` スキルの「点検」の節を読んでから実行してください。

## 点検する項目

| # | 項目 | 見つけ方 |
|---|---|---|
| 1 | リンク切れ | `[[名前]]` があるのに、その名前のファイルが無い |
| 2 | 孤立ノート | どこからもリンクされておらず、どこへもリンクしていない |
| 3 | 受信箱の滞留 | `01_受信箱` に30日以上置かれたまま |
| 4 | 空のノート | 見出しだけ、または本文が2行未満 |
| 5 | 重複 | 似た名前・似た内容のノートが複数 |
| 6 | 日付の不統一 | `YYYY-MM-DD` 以外の書き方 |
| 7 | テンプレートからの逸脱 | frontmatter に必須項目が無い |
| 8 | 置き場所の間違い | 議事録が `03_ノート` にある、など |

## 出し方

**先に全部を一覧で見せる。** 件数と、直し方の候補を添える。

```
点検結果（全 128 ノート）

リンク切れ 4件
  - 03_ノート/A.md → [[存在しないノート]]
    → 対応案: ノートを作る / リンクを外す

孤立ノート 12件
  - 01_受信箱/メモ 3.md（作成 2026-05-02、本文2行）
    → 対応案: 03_ノートへ移す / 削除 / このまま

...
```

そのうえで聞く：**「どれを直しますか？（番号で / 全部 / やめる）」**

## 絶対にやらないこと

- **確認なしに直す**
- **ノートを削除する**（削除は必ず本人にやってもらうか、明示的な指示を得る）
- 一度に何十件も自動で書き換える
- 「整理のため」にフォルダ構成を変える

## 終わったあと

直した件数と、次に気をつけるといいことを1つだけ伝える。説教しない。

そのうえで **`_ログ.md` に1行追記する**（例：`- 点検：リンク切れ4件を修正、孤立ノート12件は据え置き`）。
何も直さなかった場合は書かない。
