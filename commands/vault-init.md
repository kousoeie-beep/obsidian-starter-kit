---
description: Obsidian の vault を作る。質問は1つだけで、フォルダ・テンプレート・設定・最初のノートまで揃った状態を生成する。
---

`vault-scaffold` スキルを読んでから、以下の順に実行してください。

## 1. 今の状況を確認する（ユーザーには聞かない）

- カレントディレクトリのパスと、中身が空かどうか
- `.obsidian/` があるか（あれば既存 vault。**上書きせず**、現状を報告して「足りないものを足す」モードに切り替える）
- Obsidian アプリが入っているか
  - macOS: `/Applications/Obsidian.app`
  - Windows: `%LOCALAPPDATA%\Obsidian\Obsidian.exe`
- `obsidian` CLI が使えるか（`command -v obsidian`。Windows は `Get-Command obsidian`）
- **Obsidian が起動中かどうか**
  - macOS / Linux: `pgrep -x Obsidian`
  - Windows: `Get-Process Obsidian -ErrorAction SilentlyContinue`

  起動中だと `.obsidian/` に書いた設定が終了時に上書きされるため、**設定ファイルを書く前に「Obsidian を一度終了してください」と伝えて待つ。**

### 作ってはいけない場所（必ず止まる）

次の場所では**絶対に vault を作らない**。誤爆すると大量のファイルが Obsidian の管理下に入る。

| 場所 | 対応 |
|---|---|
| ホームディレクトリ直下（`~`） | 止める |
| `~/Documents` `~/Desktop` `~/Downloads` の直下 | 止める |
| `/`、`/Users`、`C:\` などのシステム階層 | 止める |
| 既に git リポジトリのルート（`.git/` がある） | 止めて確認する |
| **`.obsidian/` は無いが、ファイルが5個以上ある** | 止めて確認する |

止めるときは、こう言う：

> ここ（`<パス>`）には既に <n> 個のファイルがあります。ここを vault にすると、
> これらが全部 Obsidian の管理下に入ります。
> 新しいフォルダを作ってそこに vault を置くことを勧めます。例：
> ```bash
> mkdir my-vault && cd my-vault
> ```
> このまま今の場所に作る場合は「ここでいい」と言ってください。

**勝手に別フォルダを作って移動しない。** 確認を取る。

## 2. 質問は1つだけ

確認できた状況を1〜2行で伝えたうえで、**この1問だけ**を聞きます。

> ここ（`<カレントディレクトリの絶対パス>`）に vault を作ります。
> **この vault は何のために使いますか？** 一言でどうぞ。
> （例：仕事のメモと議事録をためたい／勉強したことを忘れないようにしたい／
> 　　　AI に読ませる調査資料をためたい／チームで手順書を共有したい）
> ※ 場所を変えたい場合はパスを教えてください。

答えを `vault-scaffold` スキルの型（blueprint）に当てはめます。**どの型か迷っても聞き返さない。** 一番近い型を選び、生成後に「調整するか」を聞けばよい。

## 3. 一気に作る

追加の質問はしません。スキルの手順に沿って、フォルダ・`CLAUDE.md`・テンプレート・`.obsidian/` 設定・最初のノートまで作り切ります。

## 4. できたものを見せる

- 作ったフォルダとファイルを**ツリーで表示**する
- **今すぐやること3つだけ**を提示する（それ以上書かない）
  1. Obsidian を開いて「フォルダを vault として開く」でこのフォルダを選ぶ
  2. `00_はじめに.md` を読む
  3. 何か1つメモを書いてみる
- 最後に一言だけ聞く：「調整したいところはありますか？」

## 5. 使い方を知りたそうなら

「使い方が分からない」「次に何をすればいい？」と言われたら `/vault-guide` を案内する。**この場で長い説明を始めない。**

---

## やってはいけないこと

- 質問を2つ以上する（挫折の最大要因は初期設定の重さ）
- 既存の `.obsidian/` 設定やノートを黙って上書きする
- コミュニティプラグインを6つ以上入れさせる（起動が遅くなる）
- Dataview のクエリ言語を初期構成に入れる（Bases を使う）
- MCP サーバーの設定を要求する（不要。vault 直結と公式 CLI で足りる）
