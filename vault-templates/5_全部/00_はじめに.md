# はじめに

この vault は **いろいろなことを1か所にためる** ために作りました。

## まず3つだけ

1. **書く場所に迷ったら `01_受信箱`。** 整理は後でいい。
2. **ノートの中で `[[` と打つ**と、他のノートにつながる。これが Obsidian の主役。
3. **消えない。** すべて自分のパソコンの中の普通のテキストファイル。

## フォルダの意味

| フォルダ | 何を入れるか |
|---|---|
| `01_受信箱` | 行き先が決まっていないもの。**迷ったら全部ここ** |
| `02_日々の記録` | その日のこと。日記・振り返り |
| `03_議事録` | MTGごとに1ノート |
| `04_案件` | 案件・プロジェクトごとに1ノート |
| `05_手順書` | やり方・マニュアル |
| `06_人と組織` | 取引先・社内メンバー |
| `07_学び` | 読んだ本・記事と、自分の言葉でまとめたもの |
| `Templates` | ひな形。自分では触らなくていい |
| `Attachments` | 貼った画像やPDFの置き場。自動で入る |

> **フォルダが多いと感じたら、使わないものは削って構いません。**
> 3か月使って一度も開かなかったフォルダは、たぶん要りません。

## もらった資料の置き場

| フォルダ | 何を入れるか |
|---|---|
| `.raw` | **人からもらった資料。** PDF・録音・参考記事・スクショなど |

**`.raw` の中身は書き換えません。** 原本として残し、読んで自分の言葉に直したものを
別のフォルダに書きます。こうしておくと「これは誰の意見だったか」が後から分かります。

> Obsidian の画面には出てきません（先頭がドットのフォルダは隠されます）。
> Finder / エクスプローラーから入れてください。

## AI が書いていくファイル

| ファイル | 中身 |
|---|---|
| `_ログ.md` | AI が何をしたかの履歴。新しいものが上 |
| `_いまの文脈.md` | いまの状況。次に開いたときに AI が最初に読む |
| `index.md` | 目次。何がどこにあるか |

**この2つは自分で書かなくて構いません。** 使っているうちに勝手に溜まります。

## よく使う操作

| やりたいこと | 操作 |
|---|---|
| 新しいノート | `Cmd+N` |
| 別のノートを探す | `Cmd+O` |
| 全部から検索 | `Cmd+Shift+F` |
| 何でもできる窓 | `Cmd+P` |
| ノートをつなぐ | 本文で `[[` と打つ |

※ Windows は `Cmd` を `Ctrl` に読み替えてください。

## 続けるコツ

- **全部のフォルダを使おうとしない。** 使うものだけ使えばいい
- **きれいに書こうとしない。** 走り書きでいい。後から AI に整えてもらえる
- **毎日書かなくていい。** 思い出したときに開けばいい
